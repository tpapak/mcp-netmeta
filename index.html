netmeta MCP Server

Network meta-analysis for AI assistants via the R netmeta package. Run frequentist NMA, retrieve rankings, league tables, and network graphs from any MCP-compatible client.

Hosted server

A public instance is running at Aristotle University of Thessaloniki. No installation or API key needed.

netmeta MCP https://biostatistics.med.auth.gr/mcp/netmeta/mcp Live

Add it to your client config and restart the client:

{
  "mcpServers": {
    "netmeta": {
      "url": "https://biostatistics.med.auth.gr/mcp/netmeta/mcp"
    }
  }
}

Self-hosted installation

Option A — Docker (recommended)

git clone --recurse-submodules https://github.com/tpapak/mcp.git
cd mcp/netmeta
docker compose up -d

The MCP endpoint will be available at http://localhost:8000/mcp.

Option B — Native (conda)

Prerequisites: Python 3.10+, R 4.0+, conda or miniconda.

# 1. Clone
git clone https://github.com/tpapak/mcp-netmeta.git
cd mcp-netmeta

# 2. Create environment
conda env create -f environment.yml
conda activate netmeta-mcp

# 3. Install netmeta R package (pinned version)
R -e "remotes::install_github('guido-s/netmeta@5ecfc1d7739c3df360a694d60af0563bc43d68ea')"

# 4. Install the Python package
pip install -e .

# 5. Run (stdio — for local MCP clients)
netmeta-mcp

# 5. Or run HTTP server (for web clients / ellmer)
python -m netmeta_mcp.http_server
# → http://localhost:8000/mcp
The conda environment installs R from conda-forge. If you already have a system R with netmeta installed, you can skip creating the environment and run pip install -e . directly, then netmeta-mcp.

Tools

csv_to_json
Convert pairwise, arm-level binary, or arm-level continuous CSV to JSON. Returns the parsed data and the suggested next step.
pairwise_to_netmeta
Convert arm-level data (events/n or mean/sd/n) to pairwise contrasts ready for runnetmeta.
runnetmeta
Run network meta-analysis. Returns treatments, fixed and random effect estimates, heterogeneity (τ², I²), and inconsistency statistics.
get_network_graph
Returns nodes (treatments) and edges (comparisons with study counts) from the last runnetmeta call.
get_league_table
Full matrix of all pairwise treatment comparisons (effects and 95% CIs). Fixed or random effects.
get_ranking
P-score treatment rankings (0–1, higher is better). Fixed or random effects.
get_forest_data
Effect estimates and CIs for all treatments vs a reference. Input for forest plot visualisation.

Data formats

Pairwise contrasts

Use runnetmeta directly. Required columns:

study,treat1,treat2,TE,seTE
Study1,Placebo,DrugA,0.51,0.20
Study2,Placebo,DrugB,0.83,0.25
Study3,DrugA,DrugB,0.30,0.22

TE is on the log scale for OR / RR; use the natural scale for MD / SMD.

Arm-level binary

Pass through pairwise_to_netmeta first:

study,treatment,events,n
Trial1,Placebo,20,100
Trial1,DrugA,35,100
Trial2,Placebo,18,80
Trial2,DrugB,30,80

Arm-level continuous

study,treatment,mean,sd,n
Study1,Placebo,2.1,1.5,50
Study1,DrugA,3.8,1.4,48

Using with ellmer (R)

ellmer lets you call MCP tools from R. Start the HTTP server first, then:

library(ellmer)

# Register tools
netmeta_tools <- mcp_tools("http://localhost:8000/mcp")

# Create chat (OpenAI example)
chat <- chat_openai(model = "gpt-4o", tools = netmeta_tools)

# Run analysis
chat$chat("
Run a network meta-analysis on this smoking cessation data.
Use 'No contact' as reference and show rankings.

study,treat1,treat2,TE,seTE
Study1,No contact,Self-help,0.49,0.40
Study2,No contact,Individual counselling,0.84,0.28
Study3,Self-help,Individual counselling,0.35,0.31
")

Works with any ellmer provider: chat_anthropic(), chat_gemini(), chat_ollama().

Docker details

The Dockerfile in the repo builds a self-contained image with R 4.3, netmeta, and the Python MCP server. No conda needed on the host.

# Build
docker build -t netmeta-mcp .

# Run
docker run -p 8000:8000 netmeta-mcp

# Or with docker compose (recommended — also starts verify server)
docker compose up -d

Troubleshooting

Server starts but "netmeta tool not found"

  • Restart your MCP client after changing config.
  • Verify the Python path points to the netmeta-mcp conda environment.
  • Run netmeta-mcp in a terminal to check for startup errors.

R error: netmeta not installed

conda activate netmeta-mcp
R -e "library(netmeta)"   # should load silently

# If missing:
R -e "remotes::install_github('guido-s/netmeta@5ecfc1d7739c3df360a694d60af0563bc43d68ea')"

Wrong R is being used

The server prefers the R binary inside the conda environment. Check which R is found:

conda activate netmeta-mcp
which R    # should be inside the envs/ directory

CSV parsing errors

  • Pairwise: requires study, treat1, treat2, TE, seTE
  • Arm binary: requires study, treatment, events, n
  • Arm continuous: requires study, treatment, mean, sd, n

ellmer: connection refused

python -m netmeta_mcp.http_server   # must be running
curl http://localhost:8000/mcp       # quick test
